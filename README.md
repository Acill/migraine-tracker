# Migraine Tracker Web App

A clean, mobile-optimized Progressive Web App (PWA) designed to log migraine headaches, track symptoms, and generate clean medical history reports for doctor visits.

## Features
- **Mobile & iPhone Friendly:** Quick date/time picker, interactive pain slider, and touch-friendly symptom checkboxes.
- **Local Device Storage:** Saves directly in your browser's `localStorage` so no account or backend database is needed.
- **Doctor Report / Print View:** Formatted specifically for printing or saving as a clean PDF for medical appointments.
- **Search & History:** Filter past logs instantly by symptoms, medication, or notes.
